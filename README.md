# Icansi Lezinhlwa

An interactive isiZulu periodic table with all 118 elements, category filters,
pixel-art illustrations, and woven grass-mat styling.

Open `index.html` in a modern browser. No build step is required.

## Sources

Element data and summaries: https://github.com/Bowserinator/Periodic-Table-JSON

isiZulu names: the included `Chemical_elements_in_English_and_isiZulu_term_list.pdf`.

## Hosting

Deploy as a static site on Vercel using the Other framework preset.
Leave the build command unset and use the repository root as the output directory.
